# Roadmap

This file takes precedence over the [organisation roadmap](https://github.com/netresearch/.github/blob/main/ROADMAP.md) for this repository.

## Status

AI Chat is a proof of concept in the TYPO3 state `alpha` (`ext_emconf.php`). It explores whether agent-like behaviour works in the TYPO3 backend (see [README.md](README.md)) and is not meant for production use. Its version is 0.x: under [Semantic Versioning](https://semver.org/spec/v2.0.0.html#spec-item-4), which [CHANGELOG.md](CHANGELOG.md) follows, any release can change its features, configuration and stored data.

## Planned and excluded work

The planned and excluded work of the organisation roadmap applies, with one difference that follows from the status above: there is no promise that features, configuration or stored data stay compatible from one 0.x release to the next.

## Changes to this roadmap

This file changes when the extension leaves the alpha state.
