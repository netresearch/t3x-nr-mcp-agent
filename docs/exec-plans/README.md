# Exec plans

Execution plans for multi-session agent tasks. Keep plans small and dated.

- `active/` — plans currently being worked on
- `completed/` — finished plans, kept for context

Format: one Markdown file per plan (`YYYY-MM-DD-slug.md`) with goal, constraints, ordered steps, and verification commands. Move the file from `active/` to `completed/` when the work is merged.
